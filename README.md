Архитектура MVC - Model, View, Controller
Model - Хранит все данные об игре, их логику и изменение физики.
View - Отвечает за отрисовку всего что аходится на экране
Controller - Обрабатывает нажатия и отвечает за переключение между состояниями
Settings - Константы используемые в коде
Tests - тесты работоспособности проекта
Main - запуск игры
